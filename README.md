# Shamus Creates Music Portfolio

A responsive, single-page artist portfolio for **Shamus Creates — From Prompt To Playback**.

## Included
- Dark editorial design with warm red/amber accents
- Spotify artist embeds and direct Spotify links
- Links to YouTube and Linktree
- Responsive desktop/mobile layout
- No build tools or paid hosting required

## Publish with GitHub Pages
1. Create a **new public repository** named `shamus-creates-music` in the `JamesDrum1975` GitHub account.
2. Upload `index.html` and this `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The project URL should be:
   `https://jamesdrum1975.github.io/shamus-creates-music/`

GitHub Pages can take several minutes to publish after setup.

## Easy updates
- Update the Spotify artist ID/link in `index.html` if your artist profile changes.
- Add a specific song or album by replacing one of the Spotify embeds with the embed URL for that release.
- Replace the abstract hero artwork in the CSS with your own cover art when ready.

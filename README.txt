SHAMUS CREATES WEBSITE VISUAL REFRESH

This package contains an updated index.html for the Shamus Creates music portfolio.

What changed:
- Uses the illustrated portrait from the public Images repository as the homepage hero image.
- Applies a bolder yellow, red, blue, black, and warm off-white palette inspired by the supplied references.
- Updates headline/button styling and adds a Detroit skyline artwork strip.
- Preserves Spotify artist/track embeds and the existing Spotify, YouTube, and Linktree links.

To publish:
1. Open https://github.com/ShamusCreatesOfficial2026/shamus-creates-music
2. Open index.html and choose Edit (pencil), or upload this index.html to replace it.
3. Commit the change to the main branch.

The image references point to files in the public repository:
https://github.com/ShamusCreatesOfficial2026/Images
